### 消息头像和名称修改

基于widget已有监听: ws message.created 事件和 /api/v1/widget/messages?website_token=xxx&cw_conversation=eyJhbGciOiJIUzI1NiJ9.yyy http请求

widget获取的 message数据结构里, content_attributes里添加了一些 my_ext开头的字段

my_ext_bot_info, 这个字段的值是一个json字符串, 里面包含了头像和名称等信息, 你可以在widget里解析这个字段, 获取头像和名称的信息, 然后修改消息的显示逻辑, 将头像和名称替换

比如消息体

```json
{
  "message": {
    "event": "message.created",
    "data": {
      "conversation_id": 33,
      "id": 555702984,
      "content_attributes": {
        "my_ext_bot_info": {
          "name": "需要变更的bot名称",
          "avatar": "https://avatars.githubusercontent.com/u/8010600?v=4"
        }
      }
    }
  }
}
```

无论是 ws message.created 事件和 /api/v1/widget/messages
如果 content_attributes.my_ext_bot_info 存在, 就用里面的头像和名称替换掉原来的头像和名称, 这样就实现了消息头像和名称的修改功能
注意不要影响原有逻辑
